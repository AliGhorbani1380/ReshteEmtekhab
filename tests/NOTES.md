# وضعیت آزمون‌ها

- `npm test`: آزمون ترتیب ۱۳۶ ردیف، یکتایی شناسه‌ها، هماهنگی فایل داده با پیش‌فرض و وجود عکس‌ها.
- آزمون دستی/مرورگری با Chromium (۲۰۲۶-۱۰-۰۹): بارگذاری ۱۳۶ ردیف، ۲ انتخاب غیرفعال، ویرایش، واگرد، انتقال به رتبه ۵، جستجو، خروجی JSON، PDF، چیدمان موبایل، جابه‌جایی با موس و لمس موبایل — موفق.
- PDF آزمایشی در Chromium ساخته و با PyMuPDF باز و بررسی شد: ۶ صفحه A4، نمایش درست متن فارسی. خروجی مستقیم از نوع raster است؛ متن PDF قابل انتخاب نیست.

این نتیجه فقط صحت عملکرد فنی اپ را تأیید می‌کند؛ کدرشته‌های بازنویسی‌شده باید با دفترچه سنجش مقابله شوند.

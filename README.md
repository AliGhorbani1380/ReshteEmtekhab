# اولویت‌چین — سامانه مدیریت انتخاب رشته

وب‌اپ فارسی و کاملاً راست‌به‌چپ برای تغییر ترتیب انتخاب‌های کنکور، ویرایش کدرشته و گرفتن PDF. **بدون سرور، بدون دیتابیس، بدون نیاز به npm و بدون ارسال اطلاعات به اینترنت.**

## امکانات

- ۱۳۶ انتخاب اولیه بازنویسی‌شده از روی ۸ تصویر دست‌نویس، به همان ترتیب؛ دو ردیف شماره ۴۰ و ۵۰ به دلیل خط‌خوردگی غیرفعال هستند.
- جابه‌جایی با کشیدن دستگیره (موس / موبایل)، انتقال مستقیم به شماره اولویت دلخواه و Alt+↑/↓ روی دستگیره.
- ویرایش نام رشته/دانشگاه، کدرشته، وضعیت فعال/غیرفعال و یادداشت؛ افزودن، تکرار و حذف.
- جستجو، دسته‌بندی رشته‌ها، فیلتر موارد غیرفعال و موارد نیازمند بازبینی.
- واگرد/بازانجام (Ctrl+Z / Ctrl+Y) و ذخیره خودکار در localStorage.
- خروجی PDF مستقیم با فونت فارسیِ رندرشده در مرورگر و صفحه‌بندی A4، یا چاپ مرورگر برای PDF دارای متن قابل انتخاب.
- خروجی CSV سازگار با Excel، پشتیبان JSON و بازیابی فایل JSON.
- مشاهده خود تصاویر اصلی و تطبیق هر ردیف با تصویر مربوط.

## ⚠️ دقت داده‌ها

داده‌ها به صورت **دستی از عکس‌های دست‌نویس بازنویسی** شده‌اند. به ویژه بعضی کدرشته‌ها ناخوانا یا مبهم‌اند؛ ردیف‌های دارای ابهام با پرچم «بازبینی» مشخص شده‌اند. سایر ردیف‌ها هم باید پیش از ثبت نهایی با **دفترچه رسمی سازمان سنجش** مطابقت داده شوند. این نرم‌افزار هیچ ادعایی درباره صحت، ظرفیت، وجود کدرشته یا شانس قبولی ندارد. کدهای تکراری نمایش هشدار می‌گیرند، اما عمداً خودکار پاک نمی‌شوند.

در تصویر مربوط به ردیف‌های ۱۱۵ تا ۱۳۲، یک سطر اضافیِ خط‌خورده میان ردیف‌های ۱۲۳ و ۱۲۴ وجود دارد که شماره قابل‌اعتماد/کدرشته ندارد؛ برای حفظ ترتیب شماره‌گذاری ۱ تا ۱۳۶ آن سطر به انتخاب‌های پیش‌فرض اضافه نشده است (در عکس اصلی باقی است). ردیف‌های شماره‌دار ۴۰ و ۵۰ در برنامه غیرفعال‌اند.

## اجرای محلی

این پروژه فقط HTML/CSS/JS است؛ با یک سرور فایل استاتیک اجرا می‌شود:

```bash
python3 -m http.server 8000
```

در مرورگر برو به `http://localhost:8000`.

## قرار دادن در GitHub Pages

1. در GitHub یک repository جدید بساز (مثلاً `olaviatchin`).
2. محتویات همین پوشه را **مستقیماً در ریشه repository** آپلود کن (نه پوشه والد).
3. در GitHub وارد **Settings → Pages** شو.
4. در **Build and deployment → Source** گزینه **Deploy from a branch** را انتخاب کن.
5. **Branch: main** و **Folder: /(root)** را انتخاب و Save کن.
6. بعد از انتشار، سایت در نشانی مشابه `https://USERNAME.github.io/olaviatchin/` در دسترس است.

هیچ کلید API یا تنظیم دامنه لازم نیست. برای مخزن خصوصی نیز وضعیت دسترسی Pages به تنظیمات و نوع حساب بستگی دارد.

## ساختار

```text
index.html             صفحه اصلی
src/styles.css         ظاهر و ریسپانسیو
src/app.js             مدیریت انتخاب‌ها، ویرایش و ذخیره
src/pdf.js             تولید PDF آفلاین بدون کتابخانه خارجی
src/data.js            داده اولیه مورد استفاده سایت
src/seed.json          داده اولیه در قالب قابل‌خواندن/ویرایش
src/seed-raw.txt       متن بازنویسی‌شده خط‌به‌خط برای بازبینی
assets/sources/        ۸ عکس اصلی به نام‌های 1,2,3,4,5,7,8,9.jpg
assets/favicon.svg     آیکن سایت
tests/                 آزمون‌های ساختاری
```

اگر خواستی پیش‌فرض‌ها را ویرایش کنی، `src/seed.json` را اصلاح کن و خروجی به روز `src/data.js` بساز. دقت کن `data.js` متغیر `window.DEFAULT_CHOICES` را تعریف می‌کند.

## خروجی PDF

دکمه «خروجی PDF» مستقیماً یک فایل PDF چندصفحه‌ای A4 ذخیره می‌کند. برای نمایش بدون اشکال حروف فارسی، صفحات PDF به صورت تصویر با وضوح بالا ساخته می‌شوند؛ بنابراین نوشته‌های این فایل **متن قابل انتخاب یا جستجو نیستند**. برای PDF با متن قابل انتخاب، از گزینه «چاپ / PDF متنی مرورگر» و سپس «Save as PDF» استفاده کن (صفحه چاپ فقط فهرست فعال را نمایش می‌دهد).

## حریم خصوصی

تمام اطلاعات در `localStorage` مرورگر کاربر هستند. پاک شدن داده‌های مرورگر یا استفاده از دستگاه دیگر باعث از دست رفتن این فهرست می‌شود، مگر اینکه فایل پشتیبان JSON ذخیره شده باشد. تصاویر اصلی در مخزن قرار دارند؛ اگر مخزن عمومی باشد، تصاویر نیز عمومی خواهند بود.
